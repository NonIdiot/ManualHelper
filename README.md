# ManualHelper
A mod by NonIdiot that helps with creating Archipelago Randomizers (through Manual, Taskipelago, or another way) for various Celeste Mods, among other things for map creators. Also adds a gym!

Features:

 * The main feature of this mod is the presence of ManualHelper Toggles. Each can be changed by using in-map flags or the Mod Options menu, and are somewhat similar to Extended Variant Mode's variants, with a few key differences. You can read more about them [here](https://github.com/NonIdiot/ManualHelper/blob/master/TOGGLES.md).
 * A new map, called ManualHelper Gym, that helps with teaching some obscure tech that might be used in Manuals made by this mod.
 * Shortcuts to certain mods' configuration, such as a few Extended Variants, Mechanic Disable's config menu, and a few others.
 * A method for mod creators to easily add decals and text to existing maps through .txt files *instead of editing maps themselves*.
   * This includes built-in text for some Manual implementations by NonIdiot. Current implementations:
     * Downleft Contest
