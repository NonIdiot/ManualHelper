# ManualHelper
A mod by NonIdiot that helps with creating Archipelago Randomizers (through Manual, Taskipelago, or another way) for various Celeste Mods. Also adds a gym!
Features:

 * A new map, called ManualHelper Gym, that helps with teaching some obscure tech that might be used in Manuals made by this mod.
 * A method for mod creators to easily add decals and text to existing maps through .txt files *instead of editing maps themselves*.
 * *Shortcuts to certain mods' configuration, such as a few Extended Variants, Mechanic Disable's config menu, and a few others.
 * Increased functionality for the vanilla No Grabbing variant, letting players now configure whether left or right grabs are allowed individually, as well as whether non-climbjump grabbing and climbjump grabbing are toggled per direction. (There is also a new trigger to toggle individual parts of this functionality.)
